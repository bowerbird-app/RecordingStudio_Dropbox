RecordingStudioDropbox is installed.

Register the Dropbox Oauth provider, then resolve tokens with RecordingStudioDropbox::OauthToken. Turn on the Attachable add-on with enabled and client_id when you want Chooser and the file-list page. Override Oauth scopes with RecordingStudioDropbox.configuration.scopes. See the gem README for credentials keys, scopes, and ReconnectRequired.
